Smart Campus

Smart Campus is a full-stack web application built to simplify and modernize campus management. It connects students, teachers, and administrators in one system, making attendance, assignments, and communication easier to handle.

 Features
 Student Portal

Register and log in securely

View assignments, grades, and attendance

Submit assignments online

Receive announcements and notifications

 Teacher Portal

Manage class attendance

Upload and grade assignments

Post announcements

Track student performance

 Admin Panel

Manage users (students, teachers, staff)

Oversee attendance records

Assign courses and subjects

Control campus-wide announcements

 Tech Stack

Frontend: React.js (with modern hooks & components)

Backend: Node.js + Express

Database: MongoDB

Authentication: JWT with role-based access control

Other Tools:

Git & GitHub for version control

npm for package management
